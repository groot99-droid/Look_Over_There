# empty_room

An empty floor 3 hotel room, stripped: a bare concrete floor with the carpet's old adhesive, a stain where the bed stood, one bare bulb on its cord, the curtains open on a black window, and the greybox's single chair.

This room layout was dressed with the escalators, the other staircase and `clue_room`; their one README is `docs/renders/escalators/README.md` (what was built, light, brightness, gates, sources and licences). This folder holds the three stills, the plan, `bake.json` and `caps.json`.
