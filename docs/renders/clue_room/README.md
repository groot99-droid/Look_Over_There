# clue_room

A floor 3 hotel room that holds a clue: a pinboard of notes, maps, clippings and photographs of places joined by red string, a desk with a green-shaded lamp, papers everywhere. No people or figure images.

This room layout was dressed with the escalators, the other staircase and `empty_room`; their one README is `docs/renders/escalators/README.md` (what was built, light, brightness, gates, sources and licences). This folder holds the three stills, the plan, `bake.json` and `caps.json`.
