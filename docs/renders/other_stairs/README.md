# other_stairs

The other staircase: a switchback service stair through the atrium's four levels, painted concrete with a steel rail; at every landing a level number, an EXIT sign and a caged lamp.

This scene was dressed with the escalators and the room layouts `clue_room` and `empty_room`; their one README is `docs/renders/escalators/README.md` (what was built, light, brightness, gates, sources and licences). This folder holds the three stills, the plan, `bake.json` and `caps.json`.
