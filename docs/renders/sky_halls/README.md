# `sky_hall_01` to `sky_hall_04`

The connector kit's painted-sky hall placed in each at (0, 0, 0), yaw 0 by `tools/blender/kit_place.py`, from `tools/blender/build_mall_back.py`. The page draws `world/kit/sky_hall.glb` there; there is no GLB per scene. One light set: the hall is lit by its painted sky at every hour. Stills, brightness and sources: `blender/kit/README.md` and `docs/renders/kit/sky_hall/`. The rest: `docs/renders/construction/README.md`.
